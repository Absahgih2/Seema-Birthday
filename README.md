# Happy Birthday Seema 🎀💖

A magical, interactive birthday surprise website created for Seema!

## ✨ Features
- **Surprise Gift Box Entrance**: Tap the glowing gift box to start the surprise celebration with music!
- **Auto & Interactive Birthday Animations**:
  - Glowing decorative fairy bulbs with party mode.
  - Celebratory banner and festive balloon festoon.
  - Floating balloons spelling **S - E - E - M - A**!
- **Interactive 3D Cake & Candle Blowing**:
  - Candle with flickering flame.
  - "💨 Blow Candles" button and countdown with realistic rising smoke.
  - "🍰 Cut Cake" celebratory interaction.
- **Background Music**:
  - `hbd.mp3` with clean floating sound widget.
  - Automatic Web Audio API musical chime fallback in case of network issues.
- **Memory Polaroid Photo Gallery**:
  - Beautiful polaroids of Seema with heartfelt captions.
  - Full-screen Interactive Lightbox with love reaction counter (❤️).
- **Interactive Sky Lantern**:
  - Type a special birthday wish and release a glowing sky lantern into the starry sky! 🏮✨
- **Heartfelt Sister Letter**:
  - Read through touchingly written wishes and memory lines.
- **Confetti Cannon & Heart Trails**:
  - Tap anywhere or click "💖 Shower Love" for celebratory bursts!

## 🚀 How to Run Locally
Double-click `index.html` or open in any browser.
Or run with Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## 🌐 Deploy Online
- **GitHub Pages**: Go to Settings > Pages > Select `main` branch > Click Save. Your website will be live in 1 minute!
- **Render**: Create a **Static Site** (not Web Service), link your repository, set Publish Directory to `./`.
